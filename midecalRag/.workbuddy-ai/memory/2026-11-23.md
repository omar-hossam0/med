## Phase 7 provider fix (owner-approved) + 2 real bugs found

1. LLM_MAX_TOKENS=700 truncated output because Gemini 2.5 counts THINKING tokens against max_tokens (26 visible tokens, cut mid-date). Raised default to 2000 (config + .env.example).
